# 選択テキストで検索

選択したテキストを、小さな検索バーや右クリックから好きなサイトで検索できるChrome拡張機能。表示する検索先と検索バーのオン・オフを設定できます。

## インストール

1. Chromeで `chrome://extensions` を開く
2. 右上の **デベロッパーモード** をONにする
3. **「パッケージ化されていない拡張機能を読み込む」** をクリック
4. `x-search` フォルダを選択

## 使い方

文字を選択すると、近くにアイコンを並べた小さな検索バーが表示されます。アイコンをクリックすると、選択した文字で新しいタブに検索結果を開きます。アイコンにマウスを重ねるとサイト名が分かります。Escキー・×ボタン・別の場所のクリック・スクロールで閉じられます。

右クリックからも検索できます。

検索したいテキストを選択 → 右クリック → 以下の検索先を選択します（拡張機能名のサブメニュー内に表示される場合があります）。

- **「Googleで「〇〇」を検索」** → Web全体から情報を検索
- **「Xで「〇〇」を検索」** → 新規タブでXの検索結果が開く
- **「Amazon.co.jpで「〇〇」を検索」** → 新規タブでAmazon.co.jpの検索結果が開く
- **「楽天市場で「〇〇」を検索」** → 商品や価格を比較
- **「Yahoo!ショッピングで「〇〇」を検索」** → ショップや販売価格を比較
- **「メルカリで「〇〇」を検索」** → 中古品・フリマ出品や商品の相場を検索
- **「YouTubeで「〇〇」を検索」** → レビュー動画や使い方を検索
- **「Googleマップで「〇〇」を検索」** → 店名や住所から場所を検索

すでにインストール済みの場合は、`chrome://extensions` で拡張機能の再読み込みボタンをクリックすると変更が反映されます。
検索バーを使うWebページも再読み込みしてください。

## 検索先の設定

拡張機能のアイコン、または右クリックメニューの **「検索先の設定…」** から設定画面を開きます。拡張機能の詳細にある「拡張機能のオプション」からも開けます。

- **「文字選択時に検索バーを表示する」** でオン・オフを切り替えます。初期状態はオンです。オフでも右クリック検索は使えます。
- チェックを外したサイトは検索バーと右クリックメニューに表示されません。
- 初期状態では8サイトすべてがオンです。「すべてオンにする」で戻せます。
- すでに検索先を設定済みの場合は、その選択を保持します。追加された検索先を使うには、設定画面で「Google」や「メルカリ」をオンにしてください。
- 変更はこのブラウザに自動保存され、メニューに反映されます。
- すべてオフにしても「検索先の設定…」は残ります。

検索バーはHTTP/HTTPSの通常のWebページに対応しています。Chromeの設定画面・Chromeウェブストアなど拡張機能を実行できないページや、入力欄・編集中の文章では表示しません。検索サイトへの送信は検索ボタンを押したときに行います。AIおすすめをオンにすると、判定のためのTypeSafeへの送信も行います。

## JevのAIおすすめ（任意）

設定画面の「JevのAIおすすめ」にTypeSafeのAPIキーを入力し、「接続を確認して保存・オンにする」を押します。初回は `api.typesafe.ai` への接続許可を求めます。接続確認では、モデル一覧の取得と固定のサンプル文の判定を実行します。APIの利用にはTypeSafeの利用権限と利用料金が必要です。

- 初期状態はオフです。キーを保存して接続を確認するまで通常の検索だけが動きます。
- オンの間は、文字選択後に選択した文字（最大2,000文字）をTypeSafeへ送ります。2,000文字を超える選択ではAIを呼び出しません。
- 「周辺の文章も判定に使う」は別途オンにできます。選択箇所に隣接するテキストの前後最大120文字ずつ、合計最大240文字を追加で送ります。URL、ページタイトル、ページ全文、入力欄の内容は送信しません。
- キーはこのブラウザの拡張機能ストレージに保存します（Chrome同期は使用しません）。Webページへキーを渡しません。「キーを削除」で保存したキーを削除し、AIもオフにできます。
- 確信度と適合度が高い検索先を最大2個、紫色の枠と小さな印で強調します。アイコンの位置は変わりません。判定が曖昧な場合、通信失敗、2.5秒のタイムアウト時は通常表示を続けます。
- 検索アイコンの上に、文脈に合う目的を最大2個表示します。「価格を比べる」（Googleで「価格 比較」を追加）、「レビューを見る」（Googleで「レビュー」）、「使い方を見る」（YouTubeで「使い方」）、「地図で見る」（Googleマップで選択語のまま）、「口コミを見る」（Googleで「口コミ」）、「解決方法を探す」（Googleで「解決方法」）、「意味を調べる」（Googleで「意味」）に対応します。クリックしたときだけ新しいタブで検索します。
- 目的と検索先のおすすめは同じAPIリクエストで判定します。質問数が増えるため、従来より入力トークン数は増えます。設定でオフにした検索先を使う目的は出しません。AIおすすめをオフにすると目的欄も非表示になります。
- 目的欄は判定中から場所を確保して、結果が届いてもアイコンを動かしません。十分な確信がない場合や応答を得られなかった場合は「目的の提案はありません」と表示します。
- 文字選択が落ち着いてから判定し、連続呼び出しを抑えます。同じ内容の判定結果は最大100件・5分間、メモリ内だけに保持します。設定変更で破棄し、検索履歴として保存はしません。

API仕様: [TypeSafe API](https://api.typesafe.ai/docs)。実際に利用可能なモデル名は接続時の `/v1/models` から取得します。

## 開発時の確認

Node.jsで `npm test` を実行すると、検索URL、メニューの更新、設定の保持を検証できます。拡張機能の利用にNode.jsやビルドは不要です。

Node.js 22以降とChromiumまたはChrome for Testingがあれば、`CHROME_BIN="/path/to/chrome" npm run test:browser` で検索バーの表示、実際のクリック検索、設定の保存・即時反映、入力欄の除外、画面端の配置を確認できます。一時プロファイルを使用するため普段のブラウザ設定は変更しません。`SCREENSHOT_DIR` を指定するとそのフォルダに確認用の画像を保存します。

AIの自動テストはAPI応答と接続権限をモックに置き換え、実キーや実APIを使用しません。実際の日本語での提案精度と通信速度は、自分のキーを登録した接続確認と実利用で別途確認してください。

20文字以上の選択では、原文の引用語・型番・複合語などから検索語候補を最大5件提示します。候補は先にローカルで抽出し、2,000文字以内の場合はJevで優先順位を調整します。通信失敗時も抽出候補を保持します。2,000文字超では先頭20,000文字までをローカルだけで処理し、原文をJevには送りません。候補を押して検索語を切り替えた後、目的またはサイトを押してください。「原文のまま」にも戻せます。候補の切り替え時はおすすめを再判定します。候補抽出はルール方式なので、すべての固有名詞や症状を拾えるわけではありません。

## 専門サイトを探す

AIおすすめとGoogleをオンにすると「専門サイトを探す」が表示されます。クリックしたときだけ、現在の検索語（候補を選んだ場合はその候補）と許可済みの周辺文章をJevで別途判定します。追加の検索APIは不要ですが、この判定にもJevの利用料金がかかります。

MDN、GitHub、Python公式、Microsoft Learn、Appleサポート、ソニー、J-STAGE、arXiv、国立国会図書館サーチ、コトバンク、価格.com、クックパッドの12サイトから最大3件を提案します。Web全体から新しいサイトを発見する機能ではありません。サイト名とドメインを確認してクリックすると、Googleの `site:ドメイン 検索語` で検索します。サイト独自の検索フォームは使用しません。十分な適合度・確信度がない場合は提案を出しません。検索語・設定変更や検索バーを閉じた後の古い結果は表示しません。
